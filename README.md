# Jairo Quelal — Portfolio

Bilingual professional portfolio: data analytics, Power BI, Excel / VBA / Ribbon, data quality, applied machine learning, sports analytics and published NLP research.

**Website:** https://jairoequelal-ctrl.github.io/

## Structure
- `index.html`: page structure and Spanish baseline copy.
- `style.css`: responsive design.
- `app.js`: English translations, project catalog, search, category filters, Power BI tabs and dialogs.
- `assets/`: flattened protected dashboard screenshots and a small symbol font. CV and portfolio PDFs are not published.
- `.nojekyll`: serves the site without Jekyll processing.

## Update
Edit the `projects` array in `app.js` to add or update projects. Each item contains Spanish/English descriptions, scope notes, tools and an optional public repository link. Do not link private repositories as public examples.

Edit `dashboards` in `app.js` to add a screenshot. Only add permanently redacted/flattened exports: never raw reports, employee names, financial figures, operational identifiers or `.pbix` source files. The current visuals preserve the original chart shapes while hiding confidential text and values.

Project illustrations are conceptual drawings, not claimed analytical results. AutoLake and LedgerLens use synthetic data; scope and limitations are presented in the project dialogs.

## Hosting
GitHub Pages: deploy from `main`, root `/`. No package installation, server, secrets or third-party tracking is required. Updates to the publishing branch update the site through GitHub Pages.

## Review
Check project filters, search, language switching, dashboard tabs, keyboard navigation, dialogs, downloads, and mobile layout. All assets use relative URLs.
